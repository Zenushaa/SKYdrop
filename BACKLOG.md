# SKYdrop Product Backlog

## 🟩 Must-have Features

### Search and Discovery
1. **Search schools by name or address**
   - Users can search for schools using school name or address
   - Search functionality should be intuitive and responsive

2. **Handling of simple typos in search**
   - Search should be forgiving of minor spelling errors
   - Implement fuzzy search or auto-correction for common typos

### Filtering and Sorting
3. **Filter schools by grade levels**
   - Allow users to filter schools by specific grade levels (e.g., Elementary, Middle School, High School)
   - Support multiple grade level selections

4. **Filter by school type (public/private/charter)**
   - Enable filtering by school type categories
   - Users can select one or more school types

5. **Basic sort of results (distance / rating)**
   - Sort search results by distance from user location
   - Sort search results by school rating
   - Allow users to switch between sorting criteria

### Visualization and Navigation
6. **View schools on a map**
   - Display school locations on an interactive map
   - Show school markers with basic information

7. **List + map toggle for search results**
   - Provide toggle functionality between list view and map view
   - Maintain search context when switching between views

### School Information
8. **Detailed school profile page (key facts)**
   - Display comprehensive school information
   - Include key facts such as enrollment, ratings, and academic performance

9. **See school contact information**
   - Display school address, phone number, email, and website
   - Make contact information easily accessible

10. **See photos/gallery for school**
    - Show school photos in a gallery format
    - Allow users to browse through multiple images

### User Features
11. **Add schools to Favourites**
    - Allow users to save schools to a favorites list
    - Provide easy access to favorited schools

12. **Account sign-up (Email/Google)**
    - Enable user registration via email
    - Support Google OAuth for sign-up/sign-in
    - Implement secure authentication

### Legal and Privacy
13. **Privacy and data usage policy visible**
    - Display clear privacy policy
    - Make data usage policy easily accessible
    - Ensure compliance with data protection regulations
